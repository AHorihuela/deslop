# Technical English and ASD-STE100

Use this reference for procedural/support writing, an explicitly requested technical profile, or an ASD-STE100 request. The default profile borrows clarity practices; it does not claim full compliance.

The official current standard is ASD-STE100 Issue 9, dated 15 January 2025, checked on 27 October 2026. It combines writing rules with a controlled dictionary and provisions for technical terminology. [Official overview](https://www.asd-ste100.org/about_STE.html).

## Select the scope

- **Normal prose:** use the main skill and applicable voice preferences. Do not apply controlled vocabulary, remove contractions, or flatten literary voice.
- **Technical clarity:** use the practices below for procedures and support instructions when useful. Preserve meaning and the product's terms.
- **Strict STE requested:** consult the official issue, dictionary entries, and project terminology before claiming compliance. If they are unavailable, make useful clarity edits and state that full compliance was not verified. Do not invent approved-word lists or silently change obligations to match a guessed rule.

## Practical profile

Keep one topic per sentence and one action per instruction, while preserving actions that must happen together. Put required conditions before their steps. Keep necessary articles and connecting words. Use consistent terms and readable noun phrases. Preserve sequence, warnings, quantities, UI labels, code, and references. Prefer active constructions when the actor is known.

Use Alberto's existing 20-word instruction and 25-word description limits as practical targets when this profile is selected. His six-sentence paragraph limit also remains available. These limits alone do not establish STE compliance; strict review must use the standard's counting rules.

If the input is ambiguous about a condition or sequence, ask or flag it. Do not make the procedure look simpler by dropping a prerequisite. Keep unknown actors unknown. Do not replace "may" with "must," change time or aspect, or alter a protected warning to satisfy a style rule.

## Original examples

Draft: "Click Export after the file status becomes Ready, then save the downloaded file."
Edit:
1. When the file status is Ready, click Export.
2. Save the downloaded file.

Draft: "The file was deleted. The audit log does not identify who deleted it."
Keep the unknown actor. Do not write "We deleted the file."

Personal note: "I miss our ridiculous Sunday breakfasts. Somehow we always burnt the toast."
Keep its voice. A request to deslop this note does not activate strict STE.

## Compliance boundary and sources

An approved STE word has restrictions on meaning and grammatical use; technical nouns and verbs have their own rules. Ordinary plain English is therefore not automatically STE. Tools do not replace the standard. [Current official FAQ](https://www.asd-ste100.org/STE_faq.html).
